# Smart Money Research state addendum — Phase 502 (2026-11-19)

- Phase 502 supplements Phase 501 on the same open PR #157; no new branch or workflow was started.
- Fresh official-document review found that Cboe Option Quotes supports a distinct subscription **intraday delivery** mode. The product page states intraday files are delayed 15 minutes after each snapshot; the v1.1 specification has a separate intraday filename pattern containing HHMI.
- quote_datetime is the end-of-interval timestamp (ET). Volume/OHLC cover trades since the prior interval. The stream provides interval volume, NBBO, optional IV/Greeks and optional OCC SOD OI; it does **not** provide trade-by-trade prints or aggressor-side labels.
- The Option Quotes FAQ defines OI as prior-night OCC EOD OI carried as SOD and held static through the session. Treat it as SOD only; subsequent SOD changes are not signed flow.
- Standard Option Trades subscription remains daily delivery; intraday trade-level delivery requires vendor contact and its terms/cadence remain unverified. Do not infer intraday Option Trades availability from the Option Quotes subscription.
- Prospective PIT is plausible only if a lawful subscription is obtained and every file is recorded with actual first local receipt UTC, filename/HHMI, remote size/mtime, byte count, hash and revision lineage. Actionable time is actual receipt, not nominal snapshot+15m. Historical strict PIT remains uncertified because historical first-delivery vintages and a hard max delay are not documented.

These are not 335-name estimates; request a quote for the actual universe. 15m is the preferred initial pilot interval, with 60m as a lower-volume alternative.
