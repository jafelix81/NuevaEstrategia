# Phase 27K / 27L audit and Phase 27M decision — 2026-10-20

## Phase 27K: empty signal output was a code defect, not a source failure
- Run: https://github.com/jafelix81/NuevaEstrategia/actions/runs/39481291430
- Workflow conclusion: success; research artifact contains 8 snapshots and 7 transitions, with zero tickers in each snapshot.
- Root cause confirmed in the code: Phase 27K filters `IDENTIFIER_TICKER` values against the frozen 335 ticker universe. This is an incomplete identifier strategy: in N-PORT many equity holdings have no ticker identifier, some identifiers use non-US or numeric ticker values, and other rows rely on CUSIP/ISIN. The filter silently excludes those rows.

## Phase 27M — next gate
- Build a point-in-time security crosswalk with only identifiers valid/known by each snapshot knowledge date.
- Keep a security-level key per holding; current ticker must not be treated as a permanent identity.
- Audit three matching routes separately: (1) exact identifier ticker to frozen universe, (2) exact issuer CUSIP using a historically valid crosswalk, (3) ISIN only where the same-date crosswalk yields one unique security.
- Keep ambiguous/unmapped rows as audited exclusions; do not guess.
- Report attrition by stage and assert nonzero mapping before accepting any snapshot.
- No return/alpha calculation until the pilot produces nonzero, reproducible coverage for multiple periods.
- F80 remains frozen; no production changes.
